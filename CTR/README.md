## Overview

This package implements the CTR algorithm for generating targeted positive and negative rules and contrasting rules across multiple datasets.

## Repository location

The project is maintained in `CTR/` in the TULIP Lab Open Code Repository:
https://github.com/tulip-lab/open-code/tree/main/CTR

## Installation or environment

- Matlab.

## Usage

The Matlab source files are in `code/`. The manual is included as [CTR-manual.pdf](CTR-manual.pdf).

## Data

The project includes `code/sample.xlsx` as a sample workbook. The manual PDF and sample workbook are non-code resources and are not automatically covered by the repository-level MIT code licence.
