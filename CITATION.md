# Citation

If you use a specific project in this repository, please cite the associated paper listed in the root README or in that project's README.

For repository-level citation, use:

> TULIP Lab. *TULIP Lab Open Code Repository*. https://github.com/tulip-lab/open-code.

No repository-level DOI is currently recorded in this repository. A repository-level DOI, release version, complete author list, or `CITATION.cff` may be added later as an optional future enhancement.
