## Overview

This package contains code for calculating tourism demand data predictivity. The entropy calculation depends on the distance value `r`; for very small distance values, predictivity may be unavailable.

## Repository location

The project is maintained in `PREDICTIVITY/` in the TULIP Lab Open Code Repository:
https://github.com/tulip-lab/open-code/tree/main/PREDICTIVITY

## Installation or environment

- Python 3.6.

## Usage

The README does not document a full command sequence. The included Python scripts are `predictivity_length_granularity.py` and `predictivity_ssa.py`.

## Data

No standalone dataset is documented in this subproject README. Datasets used with the code should be checked for their own licence and provenance terms.
