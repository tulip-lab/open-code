## Overview

This package implements the Adam adaptive maximum imputation algorithm for collaborative filtering datasets with missing values.

## Repository location

The project is maintained in `Adam/` in the TULIP Lab Open Code Repository:
https://github.com/tulip-lab/open-code/tree/main/Adam

## Installation or environment

- Matlab.

## Usage

The Matlab source files are in `sources/`. The original README does not document a full command sequence; `sources/main.m` is the primary entry point currently included in the project.

## Data

No standalone dataset is documented in this subproject README. Datasets used with the code should be checked for their own licence and provenance terms.
